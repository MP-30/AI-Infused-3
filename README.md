# AI-Infused-3

In this repository, I continued my Generative AI learning and focused mainly on **Agents, Tool Calling, and Embeddings**.

## 1. Basic Agent

In this mini project, I experimented with building a more practical agent using multiple tools.

* Created an agent using **LangChain**.
* Defined multiple functions and provided them as tools to the agent.
* The agent can decide which tool to use based on the user's question.
* Experimented with multi-step tool calling for a more natural chat experience.
* Learned how LLMs can interact with external functions through tool calling.

## 2. Embedding Testing

In this mini project, I started exploring **text embeddings**, which are an important part of RAG systems.

* Used **Sentence Transformers** to generate embeddings from text.
* Experimented with converting text into vector representations.
* Started exploring how embeddings can be used to compare the semantic similarity between texts.
* Learned the basic concept behind embeddings and how they can be used for information retrieval.

## Learning Goal

The goal of this repository is to move from basic LLM applications toward more advanced concepts such as **Agents, Tool Calling, Embeddings, Vector Databases, and RAG**.
